# Extensión Chrome Gratuita — Recovery Studio (Instagram & WhatsApp)

Extensión propia, 100% gratuita y sin cuentas externas, preconfigurada con todas las plantillas de **Recovery Studio**. Funciona en **WhatsApp Web** (`web.whatsapp.com`) y en **Instagram** (`instagram.com/direct`).

## Cómo instalarla en Chrome / Edge / Brave (1 minuto)

1. Abre tu navegador y escribe en la barra de direcciones: `chrome://extensions` (o `edge://extensions`).
2. Activa el interruptor **Modo de desarrollador** (arriba a la derecha).
3. Haz clic en **Cargar descomprimida** (*Load unpacked*).
4. Selecciona esta carpeta: `extension-ig-whatsapp`.

## Cómo usarla

1. **Con atajos de teclado (en WhatsApp Web o Instagram DM):**
   Escribe cualquiera de estos comandos en el chat y presiona **Espacio** o **Tab**:
   - `/bienvenida` — Saludo inicial + link MercadoPago
   - `/precios` — Lista completa de precios
   - `/horarios` — Horarios de atención
   - `/ubicacion` — Dirección en Gorbea + Google Maps
   - `/primera` — Oferta primera sesión $25.000
   - `/planes` — Plan Recovery 8 y Performance 12
   - `/pagos` / `/mp` — Medios de pago y link MercadoPago
   - `/resena` — Link directo a reseña en Google
   - `/recovery` / `/agendar` — Respuestas de embudo Instagram DM
   - `/24h` / `/recordatorio24` / `/recordatorio2` / `/noshow` / `/inactivo` — Seguimiento
   - `/referido` / `/empresa` — Referidos y B2B

2. **Con el botón flotante `RS ⚡`:**
   Abajo a la derecha dentro de WhatsApp Web e Instagram verás el botón **`RS ⚡`**. Haz clic en cualquier plantilla para insertarla o copiarla en 1 clic.
